# Changelog

## 0.3.0 — Public preview

- Refined folder-first treemap, readable capacity bars and proportions, improved breadcrumbs and focus states.
- Light/dark themes and English/Korean UI controls. Some low-level diagnostic details remain in Korean.
- Read-only synthetic demo generated from the real UI; no user data or backend in the static site.
- `pyproject.toml` packaging, isolated first-launch setup, wheel/source release preparation and cross-platform core CI.
- Public documentation, security scope, contribution guidance and private-data exclusions.
- Retains pause/resume, missing-folder handling, WSL hints and one-confirmation recycle/permanent deletion.

This is an early Windows-focused preview. Large-drive performance, uncommon filesystem cases and adversarial race conditions are not exhaustively verified.

## 0.2.1 — Local development baseline

Missing-folder filtering and redirects, selected-folder index reconciliation, and WSL Ubuntu package explanations.
