# PCSpace

**큰 폴더부터 살펴보고, 필요한 파일만 남기세요.**

[English](README.md) · [웹 데모](https://sionchu.github.io/pcspace/?lang=ko) · [다운로드](https://github.com/sionchu/pcspace/releases)

PC 안에서 실행하는 폴더 중심 저장공간 관리 앱입니다. 용량 지도를 눌러 상위 폴더부터 내려가고, 정리 후보와 크기를 비교한 뒤 선택한 파일·폴더만 휴지통으로 보내거나 영구 삭제합니다.

![샘플 데이터로 촬영한 PCSpace](docs/images/demo-light.png)

## 시작하기

1. Windows 10/11에 **Python 3.12 이상**을 설치합니다. Python Launcher 또는 PATH가 필요합니다.
2. Releases의 **Source code (zip)**을 받아 압축을 풉니다.
3. **`Start-PCSpace.cmd`를 더블클릭**합니다.

처음 한 번 프로젝트 안에 `.venv`를 만들고 필요한 Python 패키지를 내려받습니다. 브라우저는 `http://127.0.0.1:8768`에서 열립니다. 실행 창을 닫으면 앱이 종료됩니다. 별도의 계정·비밀번호·Node·Remote Desktop Commander·AI API는 필요하지 않습니다. 이번 배포는 Python이 필요한 소스 배포이며 독립 실행형 EXE는 아닙니다.

## 화면 사용법

**드라이브 선택 → 분석 시작 → 큰 영역을 눌러 하위 탐색 → 체크 → 휴지통 또는 영구 삭제 → 한 번 확인** 순서입니다.

사각형 면적은 논리 크기입니다. 주황색과 후보 막대는 캐시·빌드·의존성 폴더, 오래된 임시·설치·압축 형식에 대한 검토 힌트입니다. 자동으로 불필요성을 확정하지 않습니다. 영구 삭제는 복원할 수 없고, 휴지통 이동만으로 여유 공간이 늘지는 않습니다.

시간·50만 파일 강제 중단은 없습니다. 일시정지 후 폴더 체크포인트에서 재개합니다. 삭제 사유 입력, 확인 문구 타이핑, 강제 격리는 없습니다. 시스템·인증정보·클라우드/링크·직접 지정 보호 경로는 유지합니다. 프로젝트·사진·백업이라는 이유로 일괄 잠그지는 않습니다.

상단에서 한국어/English와 라이트/다크 테마를 바꿀 수 있습니다. 저수준 오류 메시지 일부는 한국어로 표시됩니다. 데모 화면은 가상의 데이터만 사용하고 실제 PC에 접근하거나 파일을 지울 수 없습니다.

## 원격 접속과 개인정보

상태는 `%LOCALAPPDATA%\PCSpace`에 저장합니다. 이 폴더, 실제 스캔 결과, 접속 설정을 공개 저장소에 올리지 마세요. 원격 사용은 **비공개 Tailscale Serve + 본인 계정 허용 목록**을 수동 설정하는 방식입니다. 기존 서비스는 loopback에서 유지하고 인터넷 공개/Funnel은 사용하지 않습니다. 자세한 경계는 [SECURITY.md](SECURITY.md)를 참고하세요.

업데이트 전 삭제 작업이 끝났는지 확인하고 분석을 일시정지한 뒤 앱을 종료합니다. 새 소스를 별도 폴더에 풀거나 변경하지 않은 Git 복제본에서 `git pull --ff-only`로 업데이트합니다. `%LOCALAPPDATA%\PCSpace`는 교체하지 않습니다.

## 현재 한계

초기 공개 버전입니다. 압축·희소 파일·하드링크의 실제 점유량과 논리 크기는 다를 수 있습니다. 제외한 경로는 분석 합계에 포함되지 않습니다. 외부 변경·분석 중 변경·개별 파일 삭제 후에는 정확한 합계를 위해 다시 분석해야 할 수 있습니다. WSL 가상디스크는 설명만 제공하며 내부 정리나 디스크 축소는 하지 않습니다.

Windows가 데스크톱 지원 대상이며, Linux CI는 핵심 로직 검사입니다. Everything/MFT 연동, 중복 엔진, 자동 삭제, 자동 업데이트, 클라우드 로컬 사본 해제는 포함하지 않습니다. MIT 라이선스이며 백업·보안 샌드박스를 대체하지 않습니다.

설치·개발 명령, 검증과 기여 방법은 [영문 README](README.md), [TEST_REPORT.md](TEST_REPORT.md), [CONTRIBUTING.md](CONTRIBUTING.md)에 정리했습니다.
